# BTC 作战面板

BTCUSDT 永续合约的实时信息面板：方向判断、参考信号、模拟盘、新闻、风控。只提供信息，不下单，也不构成投资建议。

## 结构

| 目录 | 内容 | 运行在哪 |
|---|---|---|
| `dashboard/live/` | 面板网页。行情直接连币安公开推送（毫秒级），其他数据读 `data` 分支 | GitHub Pages |
| `monitor/` | 后台程序：新闻抓取与利多利空标注、盘面异常、经济日历、模拟盘、推送提醒，并把结果推到 `data` 分支 | Muse 服务器 |
| `backtest/` | 回测与模型训练代码，结论见 `backtest/README.md` | 本机 |
| `rules_spec.json` | 统一规则参数。规则 A / B 给回测和模拟盘；`signals` 是 2026-11-03 现行监控规格，后台和面板共用 | — |
| 私有仓库 `logitlong/btc-records` | 喊单记录、交易日志（面板「连接云端」后读写） | GitHub（私有） |

## 数据流

```
币安公开推送 ──────────────────────────────► 面板（价格、K 线、盘口、爆仓）
新闻 / 日历 / 跨市场 ─► monitor（GitHub Actions）─► data 分支 ─► 面板（新闻、模拟盘、日历、规则、波动尺子）
候选因子快照 ─► monitor ─► factor-history 分支（按天追加，不覆盖）
```

`data` 分支每次推送都会被整体覆盖，只保留一个提交。波动尺子的预测在这个分支的 `vol_ruler.json`。因子快照在另一个分支 `factor-history`，只追加、按天分文件，用来以后检验新因子，面板不读它。
